# What is copied from the source tree into vendor/, byte for byte. Paths are relative to its root and keep
# the same layout under vendor/, because the vendored code imports its neighbours by that layout
# (memory_import/redact_bridge.py puts the directory above it on sys.path; memory_ops/hindsight_pages.py imports
# omp_hub.memory.hindsight; the omp_hub modules import each other relatively).
#
#   tree <dir> [exclude <name> ...]   every file below <dir>, minus the named files and caches
#   file <path>                       one file
#
# Edit this file, run scripts/sync-vendor.sh, and commit vendor/ together with vendor/SOURCE.sha256.
